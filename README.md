# 投资组合分析与调仓模拟

基于固定行情快照的单用户原型。前端使用 React + Vite，后端使用 Node.js + Express；估值、集中度和交易校验均由后端计算。

## 环境与安装

- Node.js 22.12.0 或更新的 22.x 版本（已在 22.18.0 验证）
- npm（已在 10.9.3 验证）

下载或克隆仓库后，进入包含 `package.json` 的项目根目录，运行：

```bash
npm ci
```

无需额外下载示例数据；初始化组合位于 `data/portfolio.json`。

## 启动

保持两个终端同时运行，且使用默认端口 3000 和 5173。

终端 1：

```bash
npm start
```

终端 2（同一项目根目录）：

```bash
npm run dev
```

如果要让**同一局域网中的另一台电脑**访问这台正在运行项目的电脑，终端 2 改用：

```bash
npm run dev:lan
```

在另一台电脑的浏览器中打开终端 2 输出的 `Network` 地址，格式为 `http://<运行服务的电脑的局域网 IP>:5173/`。这里用的是**运行服务的电脑**的 IP，不是访问者的 IP；具体地址由该电脑的网络决定，README 不预填任何人的 IP。两台电脑须处于可互通的局域网，且运行服务的电脑允许访问 5173 端口。`dev:lan` 仅用于可信局域网；它不会生成公网地址。不要在 `npm run dev` 后手工附加 IP 参数。

## 验证业务流程

1. 打开页面，核对初始总资产 100000.00、现金 20000.00，以及 A01 和科技行业的超限提醒。
2. 卖出 A01 数量 100，核对现金 30000.00、A01 占比 30.00%、科技占比 50.00%，两项提醒解除。
3. 再买入 A02 数量 100，核对现金 25000.00、A02 数量 500、科技占比 55.00%，行业提醒出现。
4. 输入方案名称并保存；保存成功后方案会出现在列表中。打开它可只读查看交易和重算结果。
5. 刷新页面或重启服务后再次打开该方案，核对结果不变。原始组合仍保持现金 20000.00、A01 数量 400、A02 数量 400。

已保存方案仅包含 ID、名称、快照 ID 和有序交易操作，写入 `data/plans.json`。该运行时文件会在第一次保存时自动创建，不提交到仓库；重新打开方案时由后端重新计算。

## 测试与构建

```bash
npm test
npm run build
```

`npm test` 运行后端服务/API 测试和前端交互测试；`npm run build` 构建前端到 `dist/`。`node_modules/`、`dist/` 和运行时方案文件均已加入 `.gitignore`。

## 常见问题

- 页面无法打开：确认终端 2 显示 Vite 已启动，使用该终端打印的 `Local` 地址；确认 5173 端口未被其他程序占用。
- 页面提示无法连接后端：确认终端 1 显示 API 已启动，并可在同一电脑访问 `http://127.0.0.1:3000/api/portfolio`。
- 局域网中的其他电脑无法打开：确认使用 `npm run dev:lan`，从终端打印的 `Network` 地址访问，并检查两台电脑的网络及防火墙设置。处于不同网络的评审者应在自己的电脑克隆仓库并启动；局域网 IP 不能作为公网链接使用。
