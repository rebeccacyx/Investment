# 投资组合分析与调仓模拟

## Project Overview

基于固定价格快照的单用户全栈应用：查看原始组合、检查持仓集中度、模拟多笔调仓，并保存和重新查看方案。调仓仅用于模拟，不代表实际交易；原始组合不会被修改。验收步骤、实际结果及截图见 [VERIFY.md](VERIFY.md)。

## Requirements

- Node.js 22.18.0（验收环境）
- npm 10.x（实际验证版本：10.9.3）
- Git

## Installation

在新电脑的终端执行：

```bash
git clone https://github.com/rebeccacyx/Investment.git
cd Investment
npm ci
```

下文命令均从仓库根目录（包含 `package.json` 的目录）执行。若重新打开终端，先进入克隆得到的 `Investment` 目录。

## Initialization

初始化组合与固定行情快照已包含在仓库的 `data/portfolio.json`，安装后即可使用；无需导入数据、配置数据库或设置环境变量。首次成功保存方案时会自动创建 `data/plans.json`。该文件保存运行期间新增的方案，不随仓库提交；重启服务时保留它即可恢复方案。

## Run

在两个终端分别从仓库根目录启动，并保持运行。

终端 1（后端）：

```bash
npm start
```

终端 2（前端）：

```bash
npm run dev
```

在运行项目的同一台电脑上打开 <http://127.0.0.1:5173/>。前端使用 5173 端口，并将 `/api` 请求转发至 3000 端口的后端。

## Saved Plans

1. 在「调仓模拟」中依次添加交易。每笔交易验证成功后才会进入已确认列表。
2. 输入方案名称，点击「保存当前方案」。保存成功后，方案出现在「已保存方案」列表中。
3. 刷新页面后，在列表中点击该方案的「打开」。页面会重新计算并只读展示结果；未保存的模拟交易在刷新后不会保留。
4. 要验证服务重启后的恢复，在终端 1 按 `Ctrl+C` 停止后端，再从同一仓库根目录运行 `npm start`。刷新页面并再次从列表打开方案。保留 `data/plans.json`，即可读取先前保存的方案；原始组合仍保持不变。

## Testing

```bash
npm test
```

## Troubleshooting

- 页面无法打开：确认终端 2 显示 Vite 已启动，并检查 5173 端口是否被其他程序占用。
- 页面显示请求失败：确认终端 1 正在运行；可在同一电脑打开 <http://127.0.0.1:3000/api/portfolio> 检查后端。
- 保存的方案在重启后消失：确认重启的是同一个仓库目录，且没有删除该目录中的 `data/plans.json`。
